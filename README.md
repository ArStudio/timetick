# TimeTick

**TimeTick** — простое расписание с обратным отсчётом до следующего события.

Подходит для любых расписаний:

- 🚌 транспорта
- 🚆 поездов и электричек
- 🎓 занятий и лекций
- 📅 распорядка дня
- ⏰ любых повторяющихся или запланированных событий

Работает **без сервера и без установки** — всё находится в одном HTML-файле.

## Как пользоваться

1. Скачайте файл `timetick.html`.
2. Откройте его в **Блокноте** или любом текстовом редакторе.
3. Найдите раздел `DATA` в коде.
4. Замените примеры на свои расписания.
5. Сохраните файл.
6. Откройте `timetick.html` в браузере.

### Формат расписания

Каждое событие записывается с новой строки:

```text
08:00,Завтрак
09:00,Работа
13:00,Обед
18:00,Тренировка
22:30,Сон
```

Можно создать несколько расписаний:

```text
"Рабочий день": `08:00,Начало работы
13:00,Обед
17:00,Конец работы`,

"Транспорт": `08:15,Автобус
08:40,Автобус
09:05,Автобус`
```

После открытия файла TimeTick автоматически показывает ближайшее событие и ведёт обратный отсчёт до него.

## Особенности

- Один HTML-файл
- Не требует сервера
- Работает офлайн
- Адаптирован для телефона и компьютера
- Можно использовать для любого типа расписания
- Обратный отсчёт обновляется каждую секунду
